# Аналитика и воронки (Яндекс Метрика 93501283)

Код: `src/utils/analytics/goals.ts` (список целей), `src/app/Tracker.tsx` (отправка).

## 1. Создать цели в Метрике

Настройки → Цели → «JavaScript-событие». Идентификатор — как в таблице.

| Идентификатор | Что значит | Параметры визита |
|---|---|---|
| `lead` | **Главная цель**: звонок или переход в ВК | `type` (call/vk), `place`, `page` |
| `call_click` | Клик по телефону | `place`, `page`, `number` |
| `vk_click` | Клик по ВК | `place`, `page` |
| `cta_click` | Клик «Вызвать эвакуатор» (якорь к блоку контактов) | `place`, `page` |
| `call_block_view` | Блок «Как вызвать эвакуатор» дошёл до экрана | `page` |
| `scroll_50`, `scroll_90` | Глубина прокрутки | `page` |
| `engaged_15s` | 15 с активного времени | `page` |

`place`: `header`, `hero`, `call_block`, `footer`, `other` (ссылки без метки).

## 2. Воронки (Конверсии → Цели → «Составная цель» или отчёт «Воронка»)

**Основная воронка:** визит → `engaged_15s` → `scroll_50` → `call_block_view` → `lead`

**Воронка «через CTA»:** визит → `cta_click` → `call_block_view` → `lead`

**Услуги → заказ:** просмотр `/services/*` → `lead` (сегмент по URL страницы)

## 3. Что смотреть

- Отчёт «Достижение целей» в разрезе параметра `place` → какие кнопки реально приносят звонки.
- Сегмент «устройство = телефон» vs «ПК»: звонок с телефона — один тап, с ПК — почти нет.
- Где воронка рвётся сильнее всего: если `scroll_50` много, а `call_block_view` мало — телефон надо показывать раньше.
- Вебвизор и карта кликов уже включены (`clickmap`): ищем клики по неактивным элементам.
- Страницы с высоким трафиком и низким `lead` — первыми правим.

## Ограничение

Цели создаются только в интерфейсе Метрики (или через API с OAuth-токеном). Пока цель не создана, события уходят, но в отчётах целей не видны.
